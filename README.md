# Book Library Search Application

A beginner-friendly project using HTML, CSS and JavaScript.

## Features
- Search books by title or author using the Google Books API.
- Display book cover, title, author, publisher and publication year.
- Show loading and no-results messages.
- Save and remove favorite books using browser localStorage.
- View a book description.
- Responsive layout for desktop and mobile.

## How to run
1. Open `index.html` in your browser.
2. Search for a book, such as `Harry Potter`.
3. Use the favorite buttons to save books.

## Technologies
HTML, CSS, JavaScript, Google Books API and localStorage.

Google Books API example: https://www.googleapis.com/books/v1/volumes?q=harry+potter

This is a student project for learning basic web development and API usage.
